# Contribution policy

DizgePHP is currently maintained solely by **Cüneyt Kaya**. The project accepts bug reports and
design discussion through GitHub Issues, but does not accept external code contributions or pull
requests at this stage. This keeps the public commit history and contributor list under one
maintainer while the framework API stabilizes.

Please do not include credentials, production data or security exploit details in public issues.
For a security-sensitive report, use GitHub’s private security advisory flow.
